Dans le cadre de mon apprentissage de Next.js, j'ai développé une application appelée Foodies App.

Ce projet m'a permis d'explorer et de maîtriser les concepts de base de Next.js : 

-l'App Router 
-la gestion des pages de chargement (loading page) et (error page)
-l'utilisation du composant Image.

J'ai également intégré des hooks React, notamment useState et useEffect, afin de gérer l'état et les effets secondaires dans l'application.
